# セーリングノット インタラクティブカタログ

12種の帆船ノット（もやい結び・クリートヒッチ・フィギュアエイト等）をSVGアニメーション手順で学べるカタログ。

## 特徴

- 12ノット（係留・接続・固定・輪・装飾カテゴリ）を名前・英語名・カテゴリで検索・フィルタ
- 各ノットの手順をSVGパスで段階的アニメーション表示（自動再生・手動ステップ切替）
- 強度（★5段階）と解きやすさ（★5段階）の評価表示
- 用途タグ（係留・レスキュー・クライミング等）表示
- スプライス（アイスプライス）などの高度技術も収録

## 技術

- SVG inline描画（Canvas不使用）
- setInterval自動再生、ステップジャンプ機能
- 検索・カテゴリフィルタはリアルタイム更新
